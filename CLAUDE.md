# Portfolio — andrespino.com

Astro + Tailwind. Live at https://andrespino.com via Cloudflare Pages.

## Critical rules
- **Push to main = production deploy** (GitHub apino01/Portfolio-Website auto-deploys). Never push without explicit "ship it."
- **Never characterize classification status** of any program in copy. Program names (MK54, HELRAS, TB-29, etc.) are fine; saying which/how classified is not.
- Strict phased workflow with stop points — do not advance phases without explicit approval.
